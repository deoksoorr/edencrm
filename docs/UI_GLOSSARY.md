# UI 용어집 (R16)

화면에 노출되는 버튼·링크·확인 문구는 아래 표준 용어만 사용한다.
같은 동작에 서로 다른 단어를 쓰면 사용자가 다른 기능으로 오인한다.

새 화면·새 버튼을 만들 때 먼저 이 표를 확인하고, 표에 없는 새 용어가 필요하면
이 문서에 먼저 추가한 뒤 코드에 반영한다.

## 표준 용어

| 표준 용어 | 의미 | 쓰지 않는 표현 |
|---|---|---|
| `등록` | 새 레코드를 만든다. 목록 화면의 기본 등록 버튼은 `+ ` 접두를 붙인다(`+ 고객 등록`). 빈 목록 안내(empty state)의 CTA는 접두 없이 `고객 등록`. | 생성, 작성, 신규, 새, 등록하기, 첫 ○○ 등록하기 |
| `수정` | 기존 레코드의 내용을 바꾼다. | 편집, 정보 수정, 변경, 수정하기 |
| `삭제` | 레코드를 휴지통으로 보낸다(소프트 삭제 — 복원 가능). | 제거, 지우기, 삭제하기 |
| `저장` | 폼 입력 내용을 서버에 반영한다. | 저장하기, 확인, 적용 |
| `취소` | **폼·모달을 닫고 입력을 버린다. 데이터는 바뀌지 않는다.** 이 뜻으로만 쓴다. | 닫기, 뒤로 |
| `무효` / `무효 처리` | **금액 레코드를 비가역적으로 무효화한다.** 레코드는 남지만 집계에서 제외된다. 대상을 앞에 붙인다 — `입금 무효`, `보너스 무효`, `비용 무효`. 확인 대화상자의 실행 버튼은 `무효 처리`. | 취소, 취소 처리, 취소처리 |
| `목록으로` | 상세 화면에서 해당 목록 화면으로 돌아간다. 좌측 화살표를 쓸 경우 `← 목록으로`. | 목록, 보드, ← 직원 목록, ← 직원 성과 목록 |
| `이전으로` | 직전 화면(목록이 아닌 상위 화면)으로 돌아간다. | 돌아가기, 뒤로가기 |
| `검색` | 필터 조건을 적용해 목록을 다시 조회한다. | 조회, 적용, 필터 적용 |
| `초기화` | **필터 초기화 전용.** 검색 조건을 모두 지우고 기본 목록으로 되돌린다. 기간 필터만 지우는 경우 `기간 초기화`. | (필터 외 용도로 사용 금지 — 비번초기화 등) |
| `CSV 다운로드` | 현재 목록·표를 CSV 파일로 내려받는다. | CSV 내보내기, CSV 출력, 엑셀 다운로드 |
| `휴지통` | 소프트 삭제된 레코드 목록. 목록 화면의 `?trash=1` 모드. 최고운영자 전용. | 삭제함, 보관함, 아카이브 |
| `복원` | 휴지통의 레코드를 다시 활성 상태로 되돌린다. 최고운영자 전용. | 되살리기, 원복, 되돌리기 |
| `완전삭제` | 서버에서 영구 제거한다. 복구 불가. 최고운영자 전용. | 영구삭제, 물리삭제, 완전 삭제(띄어쓰기) |
| `지급 처리` | 보너스를 지급완료 상태로 전환한다. | 지급처리, 지급완료 처리, 지급 확정 |
| `인쇄` | 인쇄용 화면을 연다. 브라우저 인쇄 대화상자를 직접 띄우는 버튼은 `인쇄 / PDF 저장`. | 출력, 프린트 |
| `비밀번호 재발급` | 직원 계정에 새 임시 비밀번호를 발급한다. | 비번초기화, 비밀번호 초기화, 비번 재설정 |

## 주의 사항

### `취소` 와 `무효` 는 절대 섞지 않는다

`취소`는 되돌릴 수 있는 "안 하겠다"이고, `무효`는 되돌릴 수 없는 실행이다.
확인 대화상자에서 두 단어가 나란히 뜨면(`취소` = 닫기 / `취소 처리` = 실행)
사용자가 정반대 버튼을 누른다. 무효화 계열 버튼에는 반드시 `무효`를 쓴다.

단, `cancelled` **상태값의 표시 라벨**(입금 상태 `취소`, 프로젝트 상태 `취소`,
보너스 상태 `취소`)은 데이터 상태이므로 그대로 둔다. 바뀌는 것은 **행동을 지시하는
버튼·확인 문구**뿐이다.

### `등록` 과 `추가` 의 구분

- `등록` — 독립된 레코드를 새로 만든다(고객, 견적, 계약, 프로젝트, 일정, 작업일지, 보너스).
- `추가` — 이미 있는 레코드 안에 행·항목을 덧붙인다(`+ 행 추가`, `배정 추가`, `활동 추가`).

목록 화면에서 새 레코드를 만드는 주 버튼에만 `+ ` 접두를 붙인다.

### `다운로드` 는 그대로 둔다

첨부파일 링크의 `다운로드`·`보기`는 CSV 내보내기와 다른 동작이므로 통일 대상이 아니다.

### 페이지 제목과 버튼명은 일치시킨다

버튼 `지급 이력` → 도착 페이지 H1 `지급 이력`.
버튼 `+ 고객 등록` → 도착 페이지 제목 `고객 등록`.
뷰 파일 선두 docblock의 페이지명도 함께 맞춘다.

### 내부 식별자는 건드리지 않는다

`data-*` 속성, 라우트 키(`bonus.index`), CSS 클래스, PHP 변수, DB 상태값
(`cancelled`, `paid`, `unpaid`)은 표시 문구와 무관하게 유지한다.
용어 변경은 **사람이 읽는 텍스트에만** 적용한다.
