# EDEN CRM — 관리자 UI 전면 재설계 스펙 (대시보드 · 영업 파이프라인 중심)

첨부 원본 화면(사장 대시보드 16개 동일 카드 나열 + 12열 파이프라인)을 기준으로,
정보 구조 → 디자인 시스템 → 구현 → QA → 리팩토링을 하네스 에이전트별로 수행하기 위한 단일 기준 문서.

---

## 0. 재설계 원칙

1. **정보 우선순위** — 화면에 들어온 사용자가 "가장 먼저 볼 것 → 다음 행동"을 3초 안에 판단할 수 있어야 한다.
2. **그룹화** — 모든 지표를 동일 카드로 나열하지 않는다. 업무 목적(핵심/영업/공정/재무/성과/주의)별 섹션으로 묶는다.
3. **시각적 강약** — 핵심 KPI만 크게. 보조 지표는 요약 패널·칩·테이블로 밀도 있게.
4. **색상 절제** — 포인트 1색(brand blue) + 의미 색(성공/경고/위험) + 중립. 무지개 금지.
5. **밀도** — 관리자 화면은 장식보다 정보. 여백은 그룹 구분에만 크게, 항목 내부는 촘촘하게.
6. **금액 축약** — 146.4억 / 6,050만 형태. 정확값은 title(hover)·상세에서.
7. **폭 제어** — 초대형 모니터에서 콘텐츠 최대폭 1440px 제한(보드류는 예외로 가로 스크롤 허용).

## 1. 디자인 시스템 (R2)

### 1.1 타이포 위계
| 역할 | 크기/두께 |
|---|---|
| 페이지 타이틀 | 20px / 700 |
| 섹션 타이틀 | 13px / 700, 상단 라벨식(uppercase 지양, 한글) |
| KPI 값(대) | 24–28px / 700, tabular-nums |
| KPI 값(금액) | 20–22px / 700 |
| 본문 | 13.5–14px / 400–500 (최소 13px, 초저채도 회색 금지) |
| 캡션/보조 | 12px / 500, `--ink-3` |

### 1.2 색상 규율
- 포인트: `--brand #1a56db`. 상태: 성공 `--ok`, 경고 `--warn`, 위험 `--danger`, 중립 회색.
- **파이프라인 그룹색**(절제된 단색, 얇은 상단 액센트·점에만 사용):
  신규 `#64748b` · 상담 `#3b82f6` · 현장확인 `#0891b2` · 견적 `#6366f1` · 계약 `#16a34a` · 보류·종료 `#9ca3af`
- 카드 상태선(좌측 3px): 기본 중립 / 정상진행 파랑 / 연락임박 주황 / 지연 빨강 / 계약완료 초록 / 종료 회색. **한 카드에 한 상태색만.**
- 중요도: 영문 HIGH/MID/LOW → 한글 **높음/보통/낮음**. 높음만 강조(주황 텍스트칩), 보통/낮음은 무채색.

### 1.3 공통 컴포넌트 규칙
- 카드 radius 8px, border 1px `--line`, 그림자 최소. 과도한 라운드·그림자 금지.
- 섹션: `.section`(제목 + 설명 + 우측 액션 링크) → 하위에 카드/패널/칩/테이블.
- KPI 카드: 라벨 → 값(축약, title=정확값) → 증감(전월 대비) → 상태문구 → 이동 링크(전체 카드 클릭).
- 상태 칩(chip): 라벨 + 수치, 클릭 시 해당 목록으로 이동.
- 차트: 높이 축소(200→180 내), 범례 최소, 데이터 없으면 빈 차트 대신 안내문.

### 1.4 PHP/JS 헬퍼 (신규)
- `Util::moneyShort(?float): string` — 억/만 축약(억 1자리). `Util::moneyFull()` = 기존 money().
- `Util::moneyCell($n)` — `<span title="정확값">축약</span>` HTML.
- `Stages::pipelineGroups()` — 12단계 → 6그룹 매핑/색/탭 정의(단일 출처).
- `app.js` 전역 `img[data-fallback]` onerror → 로컬 SVG placeholder(도장 현장 아이콘).

## 2. 대시보드 정보구조 (R1) — 권한별 4변형

라우트 `dashboard` → 역할별 변형: super_admin·accountant=**boss**, sales_manager=**sales**, site_manager=**site**, staff=**staff**.

### 2.A boss (사장/회계) — 섹션 순서
1. **오늘의 핵심 현황** (KPI 5–6): 이번달 확정매출 · 예상순이익 · 진행 중 공사 · 지연 공사 · 계약 대기 · 미수금. 각 카드 전월대비 증감 + 상태문구 + 링크.
2. **주의가 필요한 항목** (우측 or 상단2단): 3일+ 미접촉 고객 · 계약예정일 경과 · 공정 지연 · 미수금 발생 · 직원 미배정 · 작업일지 미작성 · 검수 대기. 숫자+이동링크.
3. **영업 현황**: 신규→상담→견적→계약대기→계약완료 미니 퍼널(수치) + 전환율 + 평균 계약소요일 + **영업단계 6그룹 도넛**.
4. **재무 현황**: 확정매출·예상매출(가중)·실제원가·예상순이익·실제순이익률·목표달성률 요약 + **월별 매출·순이익 bar+line(미래 0월 제외)** + **목표 진행바(목표/현재/남은금액)**.
5. **공정 현황**: 착공예정·진행중·지연·검수대기·준공예정 상태칩.
6. **직원 성과**: 표(직원 · 담당 프로젝트수 · 매출 · 순이익 기여액 · 목표달성률). 1명이어도 표(대형 단일 막대 금지).

### 2.B sales (영업관리자)
핵심 KPI: 내(팀) 파이프라인 예상매출 · 이번달 계약 · 계약 전환율 · 목표 달성률 · 계약 임박 · 오늘 연락 필요.
영업 퍼널 + 6그룹 도넛 + 목표 진행바 + 주의(오늘 연락/3일 미접촉/계약 임박). **회사 전체 재무·타 직원 급여성 데이터 비노출.**

### 2.C site (현장관리자)
핵심 KPI: 진행 중 공사 · 착공 예정 · 지연 공사 · 검수 대기 · 직원 미배정 · 오늘 작업일지 미작성.
공정 상태칩(18공정 그룹) + 주의(지연/미배정/작업일지/검수) + 오늘·이번주 일정 요약. **매출·순이익 비노출.**

### 2.D staff (일반직원)
오늘 일정 · 이번주 일정 · 내 담당 프로젝트 · 작업할 공정 · 작업일지 미작성 · 안읽은 알림.
내 목표 달성률(있으면) 진행바. 담당 프로젝트 공정 요약. **회사 전체/금액 비노출.**

### 2.3 차트 재구성
- 월별 매출·순이익: **bar(매출)+line(순이익)**, 미래 0월 제외, 높이↓, 축 단위 억/만.
- 영업단계: **6그룹 도넛**(12색 금지), 범례 6개.
- 목표 달성률: **게이지 폐기 → 진행바 + 목표/현재/남은금액 수치**.
- 직원 성과: **표**(막대는 직원 다수일 때만).

## 3. 영업 파이프라인 재설계 (R5)

### 3.1 단계 그룹 (12유지 · 6그룹) — 단일 매핑
| 그룹 | 세부 stage_key | 탭 |
|---|---|---|
| 신규 | new_inquiry | 신규·상담 |
| 상담 | consult_booked | 신규·상담 |
| 현장확인 | site_survey | 현장·견적 |
| 견적 | quote_drafting · quote_sent · negotiating | 현장·견적 |
| 계약 | contract_pending · contract_won | 계약 |
| 보류·종료 | on_hold · no_response · lost · cancelled | 보류·종료 |

### 3.2 보드 레이아웃
- **상단 그룹 탭**: 전체 / 신규·상담 / 현장·견적 / 계약 / 보류·종료 — 해당 그룹 열만 표시.
- 열: 12 stage 열 유지(드래그 정밀도·데이터 보존). 열 폭 300px, **가로 스크롤 허용**, 헤더 sticky.
- 전체 탭에서 열은 그룹 밴드(상단 얇은 그룹색 액센트)로 시각 구분. 빈 열은 낮은 높이.
- 열 헤더: 그룹점 + 단계명 + 건수 + 예상금액 합(축약). 열 접기 토글.
- 필터 적용 시 "표시 N / 전체 M건" 표시.

### 3.3 카드 정보 축소
**기본 카드(표시):** 고객명(업체) 1줄 · 공사유형(작게) · 예상금액(축약, 강조) · 담당 · 다음연락일(+지연) · 중요도(높음만 칩) · 좌측 상태선.
**보조(작은 아이콘/캡션):** 순이익률 % · D+체류.
**카드에서 제거:** 전체 주소 · 예상원가 · 순이익 금액 · 성공률 · 가중매출 · 긴 메모 · 등록일 · 전체 태그.
주소·긴 텍스트는 1줄 ellipsis. 상태선 1색 + 중요도 칩 최대 1개(무지개 금지).

### 3.4 상세 슬라이드 패널(우측)
카드 클릭 → 우측 슬라이드오버. 표시: 고객정보 · 현재 단계 · 담당 · 예상금액/원가/순이익/순이익률 · 성공률 · 최근 상담 · 다음연락 · 견적상태 · 메모 · 활동 타임라인.
액션: 단계 변경 · 담당 변경 · 다음연락일 등록 · 상담기록 작성 · 견적 생성(링크) · 계약 전환(링크) · 보류/실주 처리.

### 3.5 필터·검색
- 검색: 고객명·업체·연락처·주소·공사유형.
- 필터: 담당 직원 · 공사유형 · 중요도 · 지연여부 · 다음연락(오늘/이번주/지남).
- 빠른 필터 칩: 오늘 연락 필요 · 3일+ 미접촉 · 고액 견적 · 계약 임박 · 장기 체류 · 미배정.
- 적용 필터 칩 표시 + 한번에 초기화.

## 4. 나머지 화면 (R6) — 공통 규격 적용
프로젝트 목록/상세 · 공정 보드(18공정 → 그룹) · 일정 · 작업일지 · 견적 · 계약 · 고객 · 직원 · 리포트 · 성과:
- 새 디자인 시스템(섹션·카드·표·배지·버튼·칩) 적용, 금액 축약, 이미지 fallback.
- 공정 보드: 파이프라인과 동일한 그룹 탭/카드 축소/상태 단순화 규격 적용(사진 onerror fallback).

## 5. 이미지·더미데이터 (R7)
- `files.download` 썸네일 전역 onerror → 로컬 SVG placeholder(엑박 제거). `object-fit:cover`.
- 도장 업무 성격 유지(현실적 회사/고객/금액/주소/상태 다양성) — 반복 패턴 축소.

## 6. QA (R8)
해상도 1920/1440/1366/모바일, 권한별(사장/영업/현장/직원) 대시보드·파이프라인·공정보드·일정, 긴데이터·이미지누락·카드증가·회귀(DnD/필터/상세/전환). before/after 스크린샷 비교.

## 7. 리팩토링 (R9)
미사용 카드/차트/CSS/JS 제거, 인라인 스타일 제거, 컴포넌트 공통화, 차트 중복 렌더 방지, 콘솔/PHP 오류 0, 서버 실행 후 완료 보고.
